## Audio / SFX Direction (all scripts)

| Element | Direction |
|---|---|
| Voice | Casual, slightly dry, conversational. Not announcer-y. Think: friend roasting bad decisions. |
| Music | Lo-fi / phonk / distorted trending audio for TikTok. Upbeat quirky for Shorts. Minimal for pitch. |
| Text overlays | Bold, 48–64pt, high contrast, short phrases only. |
| SFX | Ding for success states. Buzz/error for bad UX. Slide/click for TOS scroll. |
| Pause | 0.5–1.0 sec after punchlines so text overlay can land. |
| Captions | Always burn in captions; 80% watch without sound. |

## How to Use in NotebookLM / Gemini Video

1. Paste the **script** into NotebookLM as a source.
2. Paste the **audio direction** as a second source titled "Audio Direction."
3. Paste the **SRT** as a third source titled "Subtitles."
4. Ask Gemini:
   > "Generate video from Script 1 using the Audio Direction and Subtitles provided. Output .mp4 and .srt."
5. If Gemini can't render SRT directly, export the `.srt` text and burn it in with CapCut or Premiere Pro.

If you want, I can also generate the **corresponding CapCut project JSON / edit decision list** so you can assemble these in one click.
