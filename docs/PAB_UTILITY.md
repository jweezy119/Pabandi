# $PAB Token — Utility & Value Flow

## What $PAB Does

### 1. Trust Stake
- Users stake PAB to boost their trust score
- Higher trust = more bookings, better deals
- Staked PAB is locked → reduces circulating supply

### 2. Booking Collateral
- Bookings require PAB deposit (e.g., $25 worth)
- On check-in: deposit returned + PAB reward
- No-show: deposit slotted → redistributed to business

### 3. Agent Reputation
- Agents stake PAB for reputation tier
- Bronze: 0 PAB | Silver: 100 PAB | Gold: 500 PAB | Platinum: 2000 PAB
- Higher tier = more bookings + higher fees

### 4. Escrow
- Real estate deposits, freelance payments, sales
- PAB held in escrow → released on completion
- Platform takes 2% fee in PAB

### 5. Rewards
- Earn PAB for verified actions (check-in, review, referral)
- PAB earned can be:
  - Staked for trust boost
  - Sold on DEX for USDC
  - Used for future bookings

## The Value Loop

```
User stakes PAB → Trust score ↑ → More bookings → More PAB earned
Agent stakes PAB → Reputation ↑ → More jobs → More PAB earned
Booking made → PAB locked → Check-in → PAB returned + reward
External buyer → Buys PAB on DEX → Uses for booking → Price goes up
```

## Why the DEX Pool is Necessary

The DEX pool exists so that:
1. **Users buy PAB** to stake for trust scores
2. **Agents buy PAB** to boost reputation
3. **Earners sell PAB** they earned from rewards
4. **Fee generation** — every trade generates 0.25% fee in USDC
5. **Price discovery** — market determines PAB value based on demand

## The Key

The DEX pool is not the profit center — it's the **exchange infrastructure**. The profit comes from the **utility driving demand**. As more people use PABandi services, more PAB is bought and sold, and fees accumulate.
