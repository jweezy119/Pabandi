# Public Good Commitment

Pabandi is released under the MIT License. We consider these components public goods for commerce trust:

- Dynamic Escrow Agent (DAE)
- Proof-of-Presence (PoP) schema + event model
- Treasury yield routing logic
- Wallet attestation integration patterns

We open-source the trust and escrow primitives under MIT so the broader Web3 commerce ecosystem can build safe checkout, booking, and reputation flows.
