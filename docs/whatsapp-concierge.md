# Pabandi WhatsApp Concierge

Status: Advanced
Backend service: `server/src/services/whatsapp.smart.service.ts`
CRM: `client/src/pages/OutreachCRMPage.tsx`
Plugin catalog: `server/src/services/openwa.plugins.service.ts`
Plugin catalog source: `PluginCatalog.json`

## Advanced capabilities available
- Menu-driven self-service.
- Book, cancel, reschedule, update, status, pay, human help, FAQ.
- Plugin-aware replies.
- Session memory during the conversation.

## Use
- Frontend CRM uses advanced actions via lead smart-action controls.
- OpenWA gateway send remains available from the CRM.
- Plugin catalog remains queryable from backend plugin routes.
